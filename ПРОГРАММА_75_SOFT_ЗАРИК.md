## Концепция

**Бот «Зарик»** — 77-дневный челлендж трансформации по мотивам 75 Soft (США).
Персонаж: **Зарик** — от слова «заряд». Маленький, но мощный. Сгусток энергии внутри телефона, который появляется каждое утро с новым зарядом. Не устаёт. Не жалеет. Искренне болеет за тебя. Не тренер и не друг — что-то среднее: знает тебя лучше тренера, честнее друга.

**Тон:** Шутливый, самоироничный, вирусный. Каждое сообщение хочется скриншотить и кидать в чат с друзьями.

**Механика мотивации:** Участник ставит деньги на кону. Прошёл 77 дней → деньги вернули. Бросил → деньги остаются.

**Верификация:** Доверительная — только чекбоксы. Без фото, без доказательств.

## 💪 Тренировка — персональная прогрессия

### Упражнения
- Отжимания
- Приседания
- Пресс

### Как работает персонализация

Во время онбординга Зарик спрашивает сколько раз участник может сделать каждое упражнение. Это его **стартовая база** (`S`). Программа строится отдельно для каждого пользователя.

### Формула на каждый день

```
повторений за круг = S + (день - 1),  если день ≤ 56
повторений за круг = S + 55,          если день ≥ 57  (заморожено на уровне дня 56)
```

Верхнего потолка нет — у продвинутого участника будет больше повторений.

Количество кругов по дням — **константа для всех**:

| Период | Дни | Кругов |
|--------|-----|--------|
| Фаза 1 | 1 – 14 | 1 круг |
| Фаза 2 | 15 – 56 | 2 круга |
| Фаза 3 | 57 – 77 | 3 круга |

### Пример (база = 10)

| День | Повт/круг | Кругов | Итого |
|------|-----------|--------|-------|
| 1 | 10 | 1 | 10 |
| 7 | 16 | 1 | 16 |
| 14 | 23 | 1 | 23 |
| 15 | 24 | 2 | 48 |
| 30 | 39 | 2 | 78 |
| 56 | 65 | 2 | 130 |
| 57 | 65 | 3 | 195 |
| 77 | 65 | 3 | 195 |

### Пример (база = 20)

| День | Повт/круг | Кругов | Итого |
|------|-----------|--------|-------|
| 1 | 20 | 1 | 20 |
| 14 | 33 | 1 | 33 |
| 15 | 34 | 2 | 68 |
| 46 | 65 | 2 | 130 (достиг капа на день 46) |
| 57 | 65 | 3 | 195 |

### Каждое упражнение считается независимо
У пользователя может быть: 15 отжиманий, 25 приседаний, 10 пресса. Прогрессия для каждого своя.

## Онбординг — поток

1. `/start` → воронка (описание программы, ставка)
2. Оплата (участие + ставка)
3. **Выбор часового пояса**
4. **Тест физической формы** — Зарик спрашивает по очереди:
   - «Сколько отжиманий можешь сделать прямо сейчас, без подготовки?» → поле ввода числа
   - «Сколько приседаний?» → поле ввода числа
   - «Сколько раз пресс?» → поле ввода числа
5. Зарик подтверждает: показывает задание на День 1 и говорит «Завтра в 07:00 — начинаем!»
6. Данные сохраняются в БД, старт = завтра

## Механика рестарта — «Мягкий рестарт» (Streak Reset)

**Правило:** Пропустил день (не закрыл все 5 задач) — серия (streak) обнуляется, программа продолжается.

Для возврата денег: завершить день 77 + иметь ≥ 66 засчитанных дней из 77 (85% порог).

Не засчитанный день = день где хотя бы одна задача не отмечена.

Участник считается «выбывшим» только после прохождения полной цепочки удержания (см. ниже).

## Механика удержания при пропусках

Утреннее сообщение в 06:00 всегда содержит программу на день. При наличии пропусков — дополняется мотивирующим блоком.

| Пропусков подряд | Что делает Зарик |
|-----------------|-----------------|
| 1 день | Утреннее послание + программа на день + мотивирующий блок «вернись» |
| 2 дня | То же самое — Зарик не сдаётся |
| 3 дня | Специальное сообщение: показывает последний засчитанный день, призывает продолжить с текущего места. **Даётся 24 часа на ответ.** |
| 3 дня + 24ч без реакции | Зарик отправляет прощальное сообщение — участник выбывает (`is_active = 0`) |

**Важно:** пока участник не выбыл официально, программа продолжается и чеклист доступен. Участник может вернуться в любой момент в течение трёх пропущенных дней — Зарик это засчитает.

**Реализация в боте:**
- Утренний scheduler проверяет количество пропущенных дней подряд (`missed_streak`)
- `missed_streak = 1–2` → утреннее сообщение + мотивирующий блок
- `missed_streak = 3` → специальное сообщение удержания, ставится флаг `dropout_warning_sent_at`
- Если прошло 24ч с `dropout_warning_sent_at` и `missed_streak` всё ещё ≥ 3 → выбытие

CREATE TABLE users (
    user_id             INTEGER PRIMARY KEY,
    username            TEXT,
    first_name          TEXT,
    start_date          TEXT NOT NULL DEFAULT '2099-01-01',
    timezone            TEXT DEFAULT 'Europe/Moscow',
    onboarding_step     TEXT DEFAULT 'payment',  -- payment/timezone/pushup/squat/abs/done

    squat_start         INTEGER DEFAULT 10,
    abs_start           INTEGER DEFAULT 10,
    is_active           INTEGER DEFAULT 1,
    created_at          TEXT DEFAULT (datetime('now'))
);

CREATE TABLE task_completions (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id      INTEGER NOT NULL,
    day_number   INTEGER NOT NULL,  -- 1-77

);

    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id        INTEGER NOT NULL,
    achievement_id TEXT NOT NULL,
    earned_at      TEXT DEFAULT (datetime('now')),
    UNIQUE(user_id, achievement_id)
);

## Модуль workout.py — логика персональной тренировки

```python
MAX_REPS = 65  # Максимальный кап повторений за круг — константа

def get_circles(day: int) -> int:
    """Количество кругов по фазам — константа для всех"""
    if day <= 14:
        return 1
    elif day <= 56:
        return 2
    else:
        return 3

def get_reps_per_circle(start: int, day: int) -> int:
    """Повторений за круг для данного пользователя в данный день"""
    return min(start + (day - 1), MAX_REPS)

def get_workout(user: dict, day: int) -> dict:
    """
    Возвращает полное описание тренировки для пользователя в день D.
    user — строка из БД с pushup_start, squat_start, abs_start
    """
    circles = get_circles(day)
    
    pushup_reps = get_reps_per_circle(user['pushup_start'], day)
    squat_reps  = get_reps_per_circle(user['squat_start'],  day)
    abs_reps    = get_reps_per_circle(user['abs_start'],    day)
    
    rounds_word = "круг" if circles == 1 else ("круга" if circles == 2 else "кругов")
    
    return {
        "icon": "💪",
        "label": "Тренировка",
        "description": (
            f"Отжимания: {pushup_reps} × {circles} {rounds_word} = {pushup_reps * circles}\n"
            f"Приседания: {squat_reps} × {circles} {rounds_word} = {squat_reps * circles}\n"
            f"Пресс: {abs_reps} × {circles} {rounds_word} = {abs_reps * circles}"
        ),
        "circles": circles,
        "pushup": {"reps": pushup_reps, "total": pushup_reps * circles},
        "squat":  {"reps": squat_reps,  "total": squat_reps  * circles},
        "abs":    {"reps": abs_reps,    "total": abs_reps    * circles},
    }
```
