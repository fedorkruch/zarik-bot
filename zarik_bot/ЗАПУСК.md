# Запуск бота Зарик

## 1. Установить Python
Скачай с https://python.org/downloads и установи (если ещё нет)

## 2. Установить зависимости
Открой Терминал, перейди в папку бота и выполни:

```bash
cd "/Users/kruchfedor/Documents/Claude/Projects/Бот наставник маленьких шагов/zarik_bot"
pip3 install -r requirements.txt
```

## 3. Запустить бота

```bash
python3 bot.py
```

В терминале должно появиться:
```
🦥 Зарик запущен!
```

## 4. Проверить
Открой бота в Telegram и напиши /start

---

## Команды бота
- `/start` — начать программу (или показать текущий день)
- `/today` — задания на сегодня
- `/progress` — прогресс и тепловая карта

## Структура файлов
```
zarik_bot/
├── bot.py          — главный файл, запускать его
├── database.py     — работа с SQLite
├── content.py      — контент 21 дня
├── keyboards.py    — кнопки Telegram
├── requirements.txt
├── zarik.db        — создаётся автоматически при первом запуске
└── ЗАПУСК.md       — эта инструкция
```
