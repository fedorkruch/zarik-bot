## Деплой на Railway

**Репозиторий:** `fedorkruch/zarik-bot` (GitHub)

**Конфиг:** `railway.toml`
```toml
[build]
builder = "nixpacks"

[deploy]
startCommand = "python zarik_bot/run_bots.py"
restartPolicyType = "always"
```

**Volume:** смонтирован в `/data` — там хранится `zarik.db`. Без Volume база сбрасывается при каждом деплое.

**Деплой:**
```bash
git add .
git commit -m "описание изменений"
git push
```
Railway подхватывает пуш в `main` и деплоит автоматически (~1 мин).

**Если есть HEAD.lock (sandbox мешает):**
```bash
rm .git/HEAD.lock
git push
```

## Архитектура — как всё работает

### run_bots.py
Запускает три компонента в отдельных потоках (каждый со своим `asyncio` loop):
- `lead_thread` — @Shagov77_bot
- `prog_thread` — @Zarik_Lazy_Bot
- `webapp_thread` — aiohttp Mini App сервер на порту из `$PORT`

### База данных (SQLite / database.py)

**Таблицы:**

| Таблица | Назначение |
|---|---|
| `users` | Участники программы: дата старта, часовой пояс, онбординг, оплата, ставка, рекорды упражнений |
| `task_completions` | Выполненные задачи (user_id + day_number + task_index) |
| `user_achievements` | Разблокированные ачивки |
| `user_photos` | Фото до/после онбординга |
| `leads` | CRM лид-бота: воронка, статусы, временны́е метки |

**DATA_DIR:** путь задаётся через `$DATA_DIR`. На Railway = `/data` (Volume). Локально = папка со скриптами.

## Mini App — авторизация

Mini App открывается через `InlineKeyboardButton` с `WebAppInfo` (только так передаётся `initData`).

Кнопка «📱 МиниАПП» в нижней клавиатуре — текстовая. При нажатии бот присылает inline-кнопку «Открыть трекер» с подписанным URL.

**Подписанный URL:** `?uid=X&ts=Y&sig=Z` — действителен 10 минут, подписан HMAC(bot_token, "{uid}:{ts}").

**Валидация на сервере (`webapp_server.py`):**
1. Telegram `initData` через `X-Init-Data` хедер → HMAC-SHA256 (без поля `signature` — Bot API 8.0+)
2. Signed URL token → HMAC проверка
3. Для TEST_USER_IDS — bypass без HMAC (dev-режим)

## Оплата (ЮКасса)

- Инвойс через `send_invoice` в Telegram
- `COURSE_PRICE_KOPECKS = 6_000` (60 ₽ тест; боевой — `199_000` = 1990 ₽)
- Чек 54-ФЗ через `provider_data` (`RECEIPT_PRICE_KOPECKS` должен совпадать с `COURSE_PRICE_KOPECKS`)
- Ставка на себя — отдельная строка в чеке, хранится в `users.stake_amount`
- При выполнении 77 дней — ставка возвращается вручную (логика возврата вне бота)

**Перед боевым запуском изменить:**
```python
COURSE_PRICE_KOPECKS  = 199_000   # 1990 ₽
RECEIPT_PRICE_KOPECKS = 199_000
MIN_STAKE_KOPECKS     = 10_000    # 100 ₽ минимум
```
